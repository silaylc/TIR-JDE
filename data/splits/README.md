# Sekans bölümleri

Bu klasördeki listeler Git'e eklenir ve bir kez oluşturulduktan sonra değiştirilmez.

- `bsb_train.txt`: BSB eğitim sekansları (102)
- `bsb_test.txt`: BSB test sekansları (98, etiketler gizli)
- `val.txt`: BSB eğitim sekanslarından ayrılan doğrulama grubu (~15)
- `dev.txt`: Takipçi geliştirme için seçilen birkaç sekans
