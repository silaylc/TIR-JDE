Generating the docs
----------

Use [mkdocs](http://www.mkdocs.org/) structure to update the documentation. 

Build locally with:

    mkdocs build

Serve locally with:

    mkdocs serve

Notes
----------

Detailed per-paper notes live in Confluence (see root `README.md` → Method
provenance). This folder is for anything that should ship with the repo
itself — setup notes, design docs — as it's written.
