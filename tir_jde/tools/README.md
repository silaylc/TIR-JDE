# Araçlar

Takipçi ve deneyler için yardımcı betikler.

- `synthetic_dets.py`: Gerçek etiketlerden sahte tespit üretir (konum titreşimi, kaçırma, yanlış pozitif, skor)
- `to_mot_format.py`: Etiketleri MOTChallenge formatına dönüştürür
- `visualize.py`: Kutuları ve ID'leri kareler üzerine çizip video üretir
